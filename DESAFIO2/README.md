## Tema escolhido

Tema 4 – ChampPy: sistema de gerenciamento de campeonato de futebol (pontos corridos).

## Etapa 1

Cadastro, consulta, alteração e exclusão de equipes; registro de partidas;
listagem de resultados; classificação e ranking de aproveitamento.

## Etapa 2

Matrizes de confronto (listas aninhadas), resumo e análise estatística do
campeonato, destaques, relatório consolidado e funções recursivas
(`buscar_equipe_recursivo` e `somar_gols_recursivo`).

## Como rodar (Python)

Requer Python 3.10 ou superior (somente biblioteca padrão).

```
python champpy.py
```

Vídeo explicativo: ver `link_video.txt`.
